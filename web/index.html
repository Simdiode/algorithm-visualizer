      What do these cases mean?

      Execution Time Measurement

      For each algorithm and input size, five timing samples are collected. The middle value (median) is displayed in milliseconds (ms).

      Only the algorithm is timed. Animation, input preparation and loading Python are excluded. Short operations are repeated and averaged within each sample.

      Lower times indicate faster execution for the selected input. Results depend on your device and other applications running at the time.
